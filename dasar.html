Bab 1

Komputer itu sebenarnya apa?

Semua komputer, dari HP, laptop, sampai server bank, bekerja dengan pola yang sama: menerima masukan, mengolahnya, mengeluarkan hasil, dan menyimpan apa yang perlu diingat.

Input · masukanMenerima

Keyboard, mouse, kamera, mikrofon, sensor sentuh, file dari internet.

Process · olahMengolah

CPU menghitung, GPU menggambar, RAM menjadi meja kerjanya.

Output · keluaranMenampilkan

Monitor, speaker, printer, file yang dikirim.

Storage · simpanMengingat

SSD atau hard disk menyimpan file dan program walau listrik mati.

Contoh: kamu mengetik "halo" di WhatsApp Web. Keyboard (input) mengirim sinyal tombol. CPU (proses) menerjemahkannya menjadi huruf, browser yang sedang berada di RAM menggambar huruf itu, lalu GPU mengirim gambarnya ke monitor (output). Saat pesan terkirim, riwayat chat disimpan (storage). Semua itu terjadi dalam seperseribu detik.

Bab 3

Hardware dan software

Hardware

Semua yang bisa disentuh: CPU, RAM, kabel, monitor. Bisnis bapakmu menyewakan hardware.

Software

Program yang berjalan di atas hardware: Windows, Excel, Chrome, game. Tanpa software, hardware hanya benda mati. Tanpa hardware, software tidak bisa jalan.

Firmware

Software kecil yang tertanam permanen di dalam hardware, misalnya BIOS di motherboard. Posisinya di antara keduanya.

Bab 4

Jenis-jenis komputer

Isinya sama (CPU, RAM, penyimpanan), tapi bentuk dan kegunaannya berbeda.

PC tower

Paling mudah diperbaiki dan di-upgrade, paling bertenaga per rupiah. Cocok untuk staf di meja, desain, dan gaming.

Mini PC / Tiny

Seukuran buku, bisa ditempel di belakang monitor. Hemat tempat dan listrik. Cocok untuk admin, kasir, dan resepsionis.

All-in-One

PC menyatu dengan monitor, rapi tanpa kabel berantakan. Kalau layarnya rusak, seluruh unit harus diservis.

Laptop

Semua komponen dipadatkan plus baterai, layar, dan keyboard. Mudah dibawa, tapi lebih mahal untuk tenaga yang sama dan sulit di-upgrade.

Workstation

PC atau laptop kelas profesional dengan komponen bersertifikat untuk aplikasi seperti CAD, render, dan sains. Contoh: Dell Pro Max, HP Z, Lenovo ThinkStation.

Server

Komputer yang menyala 24 jam untuk melayani banyak pengguna sekaligus: file kantor, database, website. Biasanya dipasang di rak.

Bab 6

Cara cek spesifikasi PC di depanmu

Keterampilan pertama seorang penjual: memastikan spesifikasi unit sesuai yang tertulis, tanpa membuka casing.

  1. Settings → System → AboutNama CPU, kapasitas RAM, versi Windows. Atau tekan tombol Windows + Pause.
  2. Task Manager (Ctrl + Shift + Esc) → PerformanceCPU (jumlah core, kecepatan), Memory (kapasitas, kecepatan, jumlah slot terpakai), Disk (SSD atau HDD), GPU (nama dan VRAM).
  3. Ketik "dxdiag" di StartRingkasan sistem dan kartu grafis, termasuk versi DirectX.
  4. Ketik "msinfo32" di StartModel motherboard, versi BIOS, status Secure Boot.
  5. Ketik "tpm.msc" di StartCek TPM 2.0 untuk syarat Windows 11.
  6. Aplikasi gratis CPU-Z dan CrystalDiskInfoDetail CPU, RAM per slot, dan kesehatan SSD/HDD. Dipakai teknisi di seluruh dunia.

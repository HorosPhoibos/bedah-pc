Chapter 1

What is a computer, really?

Every computer, from a phone or a laptop to a bank's server, works the same way: it takes input, processes it, produces output, and stores what it needs to remember.

InputReceive

Keyboard, mouse, camera, microphone, touch sensor, files from the internet.

ProcessWork it out

The CPU calculates, the GPU draws, and RAM is the workbench.

OutputShow

Monitor, speakers, printer, files being sent.

StorageRemember

An SSD or hard disk keeps files and programs even with the power off.

Example: you type "hello" in WhatsApp Web. The keyboard (input) sends the key signals. The CPU (process) turns them into letters, the browser sitting in RAM draws those letters, and the GPU sends the picture to the monitor (output). When the message is sent, the chat history is saved (storage). All of that happens in a thousandth of a second.

Chapter 3

Hardware and software

Hardware

Everything you can touch: the CPU, RAM, cables, monitor. Your father's business rents out hardware.

Software

Programs that run on the hardware: Windows, Excel, Chrome, games. Without software, hardware is a lifeless object. Without hardware, software can't run.

Firmware

Small software permanently built into hardware, such as the BIOS on a motherboard. It sits between the two.

Chapter 4

Types of computers

The insides are the same (CPU, RAM, storage), but the shape and purpose differ.

Tower PC

Easiest to repair and upgrade, most power per rupiah. Suits desk staff, design, and gaming.

Mini PC / Tiny

Book-sized, can mount behind a monitor. Saves space and power. Suits admin, cashiers, and receptionists.

All-in-One

The PC is built into the monitor, tidy with no messy cables. If the screen breaks, the whole unit goes in for service.

Laptop

Every component packed in, plus a battery, screen, and keyboard. Easy to carry, but pricier for the same power and harder to upgrade.

Workstation

A professional-class PC or laptop with certified components for apps like CAD, rendering, and science. Examples: Dell Pro Max, HP Z, Lenovo ThinkStation.

Server

A computer that runs 24 hours a day serving many users at once: office files, databases, websites. Usually rack-mounted.

Chapter 6

How to check the specs of the PC in front of you

A salesperson's first skill: confirming a unit matches its listed spec without opening the case.

  1. Settings → System → AboutCPU name, RAM capacity, Windows version. Or press Windows + Pause.
  2. Task Manager (Ctrl + Shift + Esc) → PerformanceCPU (core count, speed), Memory (capacity, speed, slots used), Disk (SSD or HDD), GPU (name and VRAM).
  3. Type "dxdiag" in StartA system and graphics card summary, including the DirectX version.
  4. Type "msinfo32" in StartMotherboard model, BIOS version, Secure Boot status.
  5. Type "tpm.msc" in StartCheck for TPM 2.0, required for Windows 11.
  6. Free apps CPU-Z and CrystalDiskInfoCPU details, RAM per slot, and SSD/HDD health. Used by technicians worldwide.

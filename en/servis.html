Service Mode

Pick a case, power on the PC, watch the symptoms (fans, debug lights, beeps, the monitor), then switch it off and inspect the suspect part. This is how technicians think.

The beeps are synthesised. Every BIOS brand has its own beep patterns, so always check the motherboard manual. Many modern motherboards have no speaker and use debug lights instead.

How technicians think

No picture: the order of checks

Technicians don't guess. They start with what's easiest and most common, then narrow down until they find the cause.

1. When the power button is pressed, does anything turn on (fans, lights)?
Nothing at all → check the wall socket, the switch on the back of the PSU, the power cord, and the case power button cable to the front panel header. If all of those are fine, the PSU has probably failed.
Yes, the fans spin → go to question 2.
2. Does the monitor say "No Signal"?
Yes → check the monitor cable: it must be in the graphics card's port if there is a GPU. Check the monitor's input (HDMI 1/2/DP) is correct.
The monitor is completely off → check the monitor's power cable and its power button.
3. Which debug light stays on?
CPU → 8-pin EPS cable, CPU not supported by the BIOS, bent socket pins.
DRAM → reseat the RAM, try one stick in slot A2, clean the contacts. Wait for memory training first if the DDR5 is new.
VGA → reseat the GPU, check the GPU power cable, try another port.
BOOT → the SSD isn't detected or the boot order is wrong. Enter the BIOS to check.
4. Still not found?
Minimal boot → remove everything except the CPU, 1 RAM stick, and the cooler. Use integrated graphics if available. Add components back one at a time.
Swap with known-good parts → technicians keep spare RAM, a PSU, and a GPU that are known to work, for testing.
Equipment

What's in a technician's bag

Physical tools

  • PH2 Phillips screwdriver (case, motherboard) and PH0/PH1 (M.2, laptops)
  • Anti-static (ESD) wrist strap or mat
  • Anti-static brush and a blower / compressed air for dust
  • 99% isopropyl alcohol (IPA) and lint-free wipes
  • Thermal paste
  • Cable ties and cutters
  • Torch or headlamp
  • Plastic spudger for opening laptops

Test gear

  • A Windows installer flash drive (made with the Media Creation Tool or Ventoy)
  • PSU tester or multimeter
  • Known-good spare parts: 1 DDR4 stick, 1 DDR5 stick, a PSU, and a small GPU
  • Spare HDMI and DisplayPort cables
  • USB to SATA/NVMe adapter for reading drives outside the PC

Diagnostic software (free)

  • CPU-Z: CPU, motherboard, and per-slot RAM details
  • HWiNFO: every temperature, voltage, and fan speed
  • CrystalDiskInfo: SSD/HDD health (Good / Caution / Bad)
  • OCCT and Cinebench: CPU, GPU, and PSU stress tests
  • MemTest86 or Windows Memory Diagnostic (mdsched): RAM checks
  • Event Viewer: Windows error logs, for example "Kernel-Power 41" when a PC shuts off suddenly
  • DDU: cleans out a problematic GPU driver

Safety

  • Switch off, unplug the power cord, then press the power button once to drain leftover power before opening the case.
  • Never open a PSU or a monitor. Their capacitors can hold a dangerous charge.
  • A swollen laptop battery: don't press, puncture, or charge it. Remove it carefully and dispose of it as hazardous waste.
  • Use earthed sockets (with a metal grounding contact) so the case can't give a shock and components are safer.

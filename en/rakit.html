    Technician's order

    How to build a real PC, step by step

    Technicians follow this order so nothing has to be taken apart again. In the simulation above, you're practising steps 2–5.

    1. Prepare the desk and discharge staticA wooden table or anti-static mat, a PH2 Phillips screwdriver, and bright light. Touch unpainted metal on the case before handling components, or wear an anti-static wrist strap.
    2. Install the CPU on the motherboardStill sitting on the motherboard box, outside the case. Match the gold triangle, set it in without pressing, then close the lever.
    3. Install the M.2 SSDBefore the cooler and GPU go in, because they often cover the M.2 slot.
    4. Install the RAMSlots A2 and B2 for two sticks. Press until the clips click.
    5. Install the CPU coolerFit the backplate or bracket, apply thermal paste if there isn't any, tighten the screws diagonally, and plug the fan cable into CPU_FAN.
    6. Prepare the caseCheck the standoffs match the motherboard's holes. Fit the I/O shield if it isn't already attached to the motherboard.
    7. Put the motherboard in the caseLine the rear ports up with their openings, then screw down every standoff. Not too tight.
    8. Install the PSUPSU fan facing down if the case has a filtered vent at the bottom.
    9. Connect the power cables24-pin to the motherboard, 8-pin EPS to the CPU (top-left corner, often forgotten), then SATA power to the drives.
    10. Install the graphics cardInto the top PCIe x16 slot, screw in its bracket, then plug the PCIe or 12V-2x6 power cable all the way in.
    11. Connect the small case cablesPower and reset buttons (front panel header), front USB, front audio, and case fans. Check the manual for the front panel pin order.
    12. Power on and enter the BIOSMonitor cable into the graphics card's port. Check the CPU, RAM capacity, and SSD are detected. Enable XMP/EXPO. Be patient if DDR5 is doing memory training.
    13. Install Windows and driversFrom a USB installer. Then the chipset driver, GPU driver, and Windows Update.
    14. Test and tidy upRun a 15–30 minute stress test while watching temperatures, check every USB and audio port, then tidy the cables.
    Physical compatibility

    Why the wrong part can't be forced in

    Manufacturers deliberately use different shapes so incompatible parts can't be installed. If something has to be forced, it's almost certainly wrong.

    RAM: notch position

    DDR4 and DDR5 both have 288 pins and the same length, but the notch in the edge connector is shifted by a few millimetres. A DDR5 slot has a key in a position that only matches DDR5. Laptop RAM (SO-DIMM) is shorter and doesn't fit a desktop.

    CPU: socket

    AMD AM5 has 1,718 contacts, Intel LGA1700 has 1,700, and Intel LGA1851 (Core Ultra 200S) has 1,851. Their sizes and locking keys differ. Even sockets of the same size (LGA1700 vs LGA1851) aren't interchangeable.

    PCIe: slot length

    x1 (±25 mm), x4, x8, and x16 (±89 mm) slots. A short card can go in a long slot (an x1 Wi-Fi card works in an x16 slot), but not the other way round. An x16-shaped slot isn't necessarily wired x16. Check the label next to the slot or the manual.

    M.2: notch and length

    An M key notch is for NVMe, B+M for SATA. The length (2230/2242/2280) has to match the position of the retaining screw, which some motherboards let you move.

    Power cables: pin shapes

    Each connector pin is either square or square with rounded corners, so CPU and GPU cables can't be mixed up unless forced. If it feels stiff, check the label again.

    Size: case and cooler

    Compatibility isn't just about plugs. A 340 mm GPU won't fit a case with a 320 mm limit. A 165 mm cooler won't fit a case with a 160 mm limit. Always check these numbers in the specs.

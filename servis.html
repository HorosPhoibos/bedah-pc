Mode Servis

Pilih kasus, nyalakan PC, amati gejalanya (kipas, lampu debug, bunyi bip, layar monitor), lalu matikan dan periksa bagian yang dicurigai. Ini cara berpikir teknisi.

Bunyi bip memakai suara buatan. Tiap merek BIOS punya pola bip sendiri, jadi selalu cek manual motherboard. Banyak motherboard modern tidak punya speaker dan memakai lampu debug sebagai gantinya.

Catatan teknisi

Cara berpikir teknisi

PC tidak tampil: urutan pengecekan

Teknisi tidak menebak. Mereka mulai dari yang paling mudah dan paling sering terjadi, lalu menyempit sampai ketemu penyebabnya.

1. Saat tombol power ditekan, apakah ada yang menyala (kipas, lampu)?
Tidak sama sekali → cek stopkontak, saklar di belakang PSU, kabel power, dan kabel tombol power casing ke front panel header. Kalau semua benar, kemungkinan PSU rusak.
Ya, kipas berputar → lanjut ke pertanyaan 2.
2. Monitor menulis "No Signal"?
Ya → cek kabel monitor: harus di port kartu grafis kalau ada GPU. Cek input monitor (HDMI 1/2/DP) sudah benar.
Monitor mati total → cek kabel daya monitor dan tombol power-nya.
3. Lampu debug mana yang menyala terus?
CPU → kabel 8-pin EPS, CPU belum didukung BIOS, pin socket bengkok.
DRAM → pasang ulang RAM, coba satu keping di slot A2, bersihkan pin. Tunggu memory training dulu kalau DDR5 baru.
VGA → pasang ulang GPU, cek kabel daya GPU, coba port lain.
BOOT → SSD tidak terdeteksi atau urutan boot salah. Masuk BIOS untuk mengecek.
4. Masih belum ketemu?
Minimal boot → lepas semua kecuali CPU, 1 RAM, dan pendingin. Pakai grafis bawaan kalau ada. Tambah komponen satu per satu.
Tukar dengan yang pasti bagus → teknisi menyimpan RAM, PSU, dan GPU cadangan yang sudah pasti normal untuk menguji.
Perlengkapan

Isi tas teknisi

Alat fisik

  • Obeng Phillips PH2 (casing, motherboard) dan PH0/PH1 (M.2, laptop)
  • Gelang anti-statik (ESD) atau alas anti-statik
  • Kuas antistatik dan blower / compressed air untuk debu
  • Alkohol isopropil (IPA) 99% dan tisu bebas serat
  • Thermal paste
  • Pengikat kabel (cable tie) dan pemotong
  • Senter atau lampu kepala
  • Spudger plastik untuk membuka laptop

Alat uji

  • Flashdisk installer Windows (dibuat dengan Media Creation Tool atau Ventoy)
  • PSU tester atau multimeter
  • Komponen cadangan yang pasti normal: 1 keping RAM DDR4, 1 DDR5, PSU, dan GPU kecil
  • Kabel HDMI dan DisplayPort cadangan
  • Adapter USB ke SATA/NVMe untuk membaca drive di luar PC

Software diagnosis (gratis)

  • CPU-Z: detail CPU, motherboard, RAM per slot
  • HWiNFO: semua suhu, tegangan, dan kecepatan kipas
  • CrystalDiskInfo: kesehatan SSD/HDD (Good / Caution / Bad)
  • OCCT dan Cinebench: stress test CPU, GPU, PSU
  • MemTest86 atau Windows Memory Diagnostic (mdsched): cek RAM
  • Event Viewer: catatan error Windows, misalnya "Kernel-Power 41" saat PC mati mendadak
  • DDU: membersihkan driver GPU yang bermasalah

Keselamatan

  • Matikan, cabut kabel listrik, lalu tekan tombol power sekali untuk membuang sisa listrik sebelum membuka casing.
  • Jangan pernah membuka PSU atau monitor. Kapasitornya bisa menyimpan listrik berbahaya.
  • Baterai laptop yang menggembung: jangan ditekan, ditusuk, atau dicas. Lepaskan dengan hati-hati dan buang ke tempat limbah B3.
  • Pakai stopkontak berarde (ada kaki logam penghubung bumi) supaya casing tidak menyetrum dan komponen lebih aman.
